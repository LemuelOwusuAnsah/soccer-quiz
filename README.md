# Soccer Quiz — PHP Mini Game

> **UNDER CONSTRUCTION**
> This project is actively being built and refined. Features may change.

A lightweight, browser-based soccer general knowledge quiz built with **pure PHP** — no frameworks, no Composer, no database.

## Features

- 10 multiple-choice general knowledge soccer questions
- 15-second countdown timer per question
- Pause / Resume button
- Randomised question order each game
- Persistent Top 5 leaderboard (saved to `scores.json`)
- Clean, responsive single-page UI
- Modular structure — data, logic, storage, and rendering are separated
